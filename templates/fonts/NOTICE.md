# Fonts

The dashboard template embeds two typefaces, each under the SIL Open Font License 1.1
(https://openfontlicense.org). The copyright notices are embedded in the font files.

- Inter (`inter.woff2`), from `@fontsource-variable/inter`
- DM Sans (`dm-sans.woff2`), from `@fontsource-variable/dm-sans`
